# 🐾 Pet Language AI｜毛語 AI

AI 寵物語言與情緒照護 App

## 專案目標

建立一款可以透過 AI 分析寵物：

- 🐶 狗狗叫聲
- 🐱 貓咪叫聲
- 🎤 寵物語音
- 📷 寵物照片
- 🎥 寵物影片
- 😊 情緒與行為

並提供飼主容易理解的分析結果與照護建議。

## 核心功能

1. 上傳寵物語音
2. 上傳寵物照片
3. AI 情緒辨識
4. AI 行為分析
5. 寵物聲音分類
6. 寵物照護紀錄
7. 個人寵物資料
8. AI 寵物照護助手

## 開發目標

第一階段：
建立可運作的 MVP 測試版本。

第二階段：
加入 AI 語音、圖片與影片分析。

第三階段：
完成 iPhone App。

第四階段：
提交 Apple App Store 審核並正式上架。

## 平台

- iOS

- Cloud Database
